# 条件技能衔接

本Skill负责网站测量到优化的证据闭环。下表是按缺口选择的支持路径，不是每次必须跑完的技能清单；只读报告不升级为代码改动，已验收阶段沿用有效回执。

## 解析与交付约定

先核对当前宿主暴露的技能，再检查其用户级skills目录中的同名 `SKILL.md`。本机Codex入口为 `~/.codex/skills` 与 `~/.agents/skills`；包装入口按其说明读取真实源文件，引用资源从源目录解析，不复制第三份SOP。显式compatibility alias（如 `ego-lite-fast-path`）可没有独立Source文件，应依其链核验真正的 `ego-browser` 入口，不把占位说明当文件路径。技能不存在或真实源不可读时记录该支持步骤 `pending/blocked`，用已授权的现有方法继续，不声称已调用，也不为可选技能阻断无关步骤。

交接共享同一私有运行回执：精确站点绑定、当前模式/授权、版本与日期、声明影响全集、数据窗口/完整性、事实和未知、允许改动、验收项。支持技能返回证据与候选，主流程更新原台账；不要递归互相调用、重跑全扫或另建不一致分母。

## 按阶段选择

| 缺口或明确请求 | 支持技能 | 应吸收的结果及边界 |
| --- | --- | --- |
| 事件计划、SDK/GA4/GTM和去重验证 | `analytics` | 业务问题到触发/属性/验证的tracking plan；复用本站适配器，不因示例默认新增GA4/GTM或更换命名 |
| 经营看板、KPI与跨卡片数字不一致 | `metrics-dashboard` | 每指标的数据源、计数单位、分子/分母、窗口/时区、排除、null、刷新规则；布局服务业务，不照搬通用North Star卡片 |
| 多工具口径冲突、渠道归因 | `attribution` | 业务事实来源、归因窗口、来源差异与未关联项；默认只用解读分支，不从时间接近、direct或品牌流量反推身份/真实来源 |
| 分群、激活与成熟留存分析 | `cohort-analysis` | 起始/回访行为、成熟分母、保留期和置信限制；当前账号快照不是注册历史队列 |
| 有证据的CTA、内容入口或表单转化问题 | `cro` | 假设、反证、最小修复与防误判指标；不凭低样本、零目标或通用建议宣称流失原因 |
| 用户操作后无反馈、失败/重试不清楚 | `interaction-feedback-ux-audit` | action -> validation -> async -> result -> message -> recovery矩阵，与埋点矩阵复用同一范围；纯视觉润色不自动全审计 |
| 业务线索定义、CRM阶段和销售交接 | `revops` | 请求/有效线索/发送/送达/确认回复分别计数；不自动增加联系人、打分、丰富个人信息或营销自动化 |
| 明确要求实验设计或已有实验结果分析 | `ab-testing` / `ab-test-analysis` | 前者冻结随机分配、样本计划、主指标和停止规则，后者检验实际实验；普通前后对照不得包装为随机实验 |
| 实际代码修改、运行、测试或获准发布 | `codebase-memory` + `local-dev-workflow` | 先按宿主要求刷新实际repo合格基线，再实现并检查受影响路径；验证范围按影响面，纯SOP维护不入图 |
| 登录态取证或真实浏览器QA | `ego-lite-fast-path` -> `ego-browser` | 遵循用户指定浏览器优先；隔离QA，记录并完成/交还本任务空间；合成/拦截测试不等于生产接收 |
| 公共SEO站前检、索引/查询或可索引页面改动 | `gsc-diagnosis-scaling` | 遵循本站前检与changed/full范围规则，复用同任务有效证据；GSC查询与匿名行为不拼身份，埋点优化不自动扩页 |
| 内容到工具推荐/锚文本错配需专项核验 | `30x-seo-internal-links` | 检查所有受影响上下文、目标能力和URL owner，优先显式映射，不用任意子串推断意图；文章生产另遵循宿主既定链 |
| 数据类型、目的、处理商、保留或位置权限改变 | `privacy-policy` | 实际数据流与披露差异、需法律复核项；模板不代替法域判断，也不授权新增采集或身份关联 |
| 明确要求生命周期邮件内容/序列设计 | `emails` | 仅在许可与退订基础上设计内容；单次测试发信、签名回执、入站调试仍用本Skill的CRM参考和既有邮件SDK |
| 用户明确要定时监测/周报/后续提醒 | 宿主自动化工具，按需 `automation` | 先找匹配任务，默认只读且无可行动变化静默；复查日期、建议提醒不等于已创建监控 |
| Traks平台首次搭建或平台运维 | `traks` | 仅平台分支；已有实例接新网站不重装、不自动创建资源，不绑定任何固定站点或Worker |

## 不同步为默认规则的内容

- `events` 指会议、展会、webinar等活动营销，不是analytics事件埋点，不接入本链。
- `analytics` 的示例 `user_id`、自由文本、完整URL，及 `attribution` 的identify/跨域stitching示例，不覆盖本站匿名白名单。若用户另行请求身份关联，先重新审查目的、同意、数据最小化和授权；本SOP不默认实现。
- 不把匿名数据不足变成新增住址、精确定位、会话回放或访客去匿名的理由。账号聚合不需要这些字段。
- SEO选词、Reddit研究、建页、广告投放、AdSense、冷邮件和新站模板不是读数或埋点接入的默认后续。只有独立请求与证据门满足后转入对应流程。
- 不把相邻技能中的示例自动化、数据回填或发布步骤当作本站已授权动作。保留本SOP的unknown、隐私与完整性边界。
