# 发布与受阻恢复：限定目标，不把事故固化成脚本

仅在实际改代码、发布或遭遇对应阻塞时读取。先遵循目标仓库规则及可用的部署/codebase-memory Skill；纯方法维护不索引整个Vault，不重启图谱、不访问生产。

## 图谱生命周期与共享锁

1. 按canonical root匹配实际代码项目，不索引父级Vault/所有仓库。先list_projects和index_status，再依用户规则刷新该根的完整合格基线，保留generation、freshness和root覆盖/分页/排除理由。
2. 代码修改后检查每个受影响路径的新鲜度和coverage；detect_changes只分析diff，不刷新，也不证明untracked文件入图。CLI fallback先读help；CLI单次成功不是持续watcher，MCP连接/auto_watch及UI应独立验。
3. `pre-coordination or unverified CBM generation` 或共享锁阻塞时，列出精确连接、宿主与影响范围。默认不删锁、不禁用保护、不杀Claude/Codex；用限定源码审计继续能做的工作，记录图谱未验收。
4. 只有取得本次明确的短暂中断授权后，才正常停止/重启已确认的目标CBM连接。PID、连接数、UID、端口和socket来自当前发现，不复用旧回执的值；执行前再核身份。
5. 仅在旧daemon确已退出、socket无监听/无持有句柄且工具文档支持恢复时，评估移走失效IPC对象到可恢复私有备份。不能把“连接拒绝”单独当无主证明；不删除协调锁或索引，不操作活跃/不明归属对象。
6. 恢复后重新验证根绑定、状态、完整基线和受影响路径。旧native transport可能仍关闭，应让客户端重连；不宣称其他任务的连接已自动恢复。图谱解析缺口用限定源码补证，不把“无记录gap”当绝对完整。

## 发布门与副作用

- 先展示repo/worktree、diff与用户未提交文件、准确remote/branch、Worker/账号/资源、命令、副作用与回滚点；提交、push、deploy、secret、DNS、migration分别核本次授权。不能默认推origin/upstream，也不创建未请求分支。
- 既有Traks实例优先评估现有update-only路径，仍审阅其是否创建资源、写secret、迁移或改cron；首次部署向导不是每次接站的必经步骤。
- 远端迁移先读ledger，按完整文件名核对待迁移和已审阅SQL；不重放保留源、不因同编号猜已执行。迁移与代码发布分别留证；代码回滚不保证数据库逆转，破坏性回滚需独立方案。
- 按影响面运行测试；平台SQL/运行时边界需实际兼容验证，Node或SQLite通过不代表Workers/R2 SQL支持。核最终artifact、源码/hash/依赖、构建变体、公开资源秘密检查及构建时siteId；资源上传身份与在线版本分别核对。
- 依据实际契约依赖发布：接收端先兼容旧/新事件，独立业务提供方先支持消费端所需字段，再发布受影响producer/消费端。未改collector、事件契约或数据库时，不为固定顺序重发或迁移。最后QA读回live与历史。保留用户原有未跟踪/修改内容；确属本次维护范围时在其上增量编辑，提交清单显式审阅，不混入无关文件。
- 容量决策读取用户的Cloudflare容量规则并复核当前官方来源；使用Wrangler Total Upload未压缩值，gzip仅参考，启动/CPU/内存与资源数量是独立门。
- 只有部署没有实际读回时记录“发布完成、生产接收待验”，不把命令退出成功当埋点链路通过；SEO-facing变更另按宿主的changed/full scope规则复查，不重做无关关键词研究。

## 按证据排查，不扩大修复

| 现象 | 有界处置 | 禁止误判 |
| --- | --- | --- |
| Wrangler代理协议错误 | 核对支持的代理，仅对本任务子进程调整环境 | 全局关闭代理或将网络错误当凭据失效 |
| OAuth过期 | 经正常授权流程重新认证，脱敏核对目标 | 打印token或改用更高权限Key绕过 |
| 跨Worker读取失败 | 检查当前路由兼容设置与真实运行时；必要时用 `manual` 拒绝重定向 | 盲套 `redirect:error`；跟随任意跳转泄露token；Node测试冒充生产 |
| CLI输出完成但不退出 | 先独立核远端ledger/版本/健康及无在途任务，再仅释放本任务进程并记录 | SIGTERM后exit0证明成功；每次部署自动kill；杀其他任务 |
| collector200却无事件 | 分别检查绑定、构建配置、隐私、QA传播、过滤/限额与历史延迟 | 伪造UA绕过滤、把测试改production或认定真实用户离开 |
| MCP缺工具/数据失败 | 用安全接入步骤复核schema/权限/连接，错误保持不完整 | 旧统计替代完整质量证据或填0 |

浏览器任务沿用用户选择及Ego规则；记录并完成本任务空间，需人工登录/回复时明确handoff，不接管或关闭无关空间。

## 恢复后交接

保留原失败事实，新增带时间的恢复证据而不是覆盖旧结论。列出仍未完成项、下一条安全动作、哪些操作不可重放（send、迁移、资源创建等）。授权测试信已发且状态未明时，下次只读核对，不重复发；待用户回复不启动轮询自动化，除非用户单独要求。
