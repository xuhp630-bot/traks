# 逐站运行回执模板

将本模板填写到该站受限、Git忽略的私有状态目录；不要把真实账号、siteId、endpoint、收件人和细粒度会话证据回填本Skill。凭据仅记录变量名/安全引用位置，不填值。已有任务更新同一台账，历史结论保留日期。

## A. 理解：绑定与授权

- run_id / 创建与更新时间 / 当前负责人：
- 本次模式：MCP配置、埋点接入、全量审计、读数、CRM、优化、复查、仅SOP（按需选）。
- 按缺口选用的支持技能、实际入口/源及产出；未选/不可用原因（不加载整表）：
- 实际repo/worktree、生产origin、部署remote/branch及资源目标：
- 分析实例、siteId/property、客户端版本、schema/producer版本：
- 业务目标、主要用户任务、成功定义、支持语言/设备全集：
- 同意/DNT/GPC、私密路线、敏感字段、保留期、访问角色与外部数据处理边界：

## D. 执行与验收

- MCP：加载结果、initialize/tools/list、实际schema、准确站点最小读取、授权错误；模型配置有需求时另记requested_model/actual_model/证据，不记录Key。
- QA：测试场景/预期/实际、真实副作用授权、会话隔离/迟到QA、受理与持久读回；失败不抹去。
- 看板：默认/原始视图、延迟加载、切窗/刷新含独立业务、部分失败/重试/空态、桌面/手机；UI/MCP同范围对账。页面健康mock与真实收数分开。
- 发布：代码diff/hash、测试与未测项、secret仅存在状态、migration ledger、artifact/配置变体、remote/branch、版本与回滚限制。
- CRM：独立QA记录及发送幂等引用、受理/签名送达/用户实际回复/候选/人工确认各自证据；uncertain后下一步仅核对，不重发。
- 图谱/浏览器：实际根freshness与局部限制、持续连接与CLI区别、本任务空间完成或handoff状态。

## E. 数据包清单

- 数据来源/取得时间、schema、站点、时区、UTC from/to及包含/排除边界、period、filters、版本：
- 窗口是否结束、扫描是否完整、是否仅窗口证据而非生命周期：
- 分页数、cursor推进、排序、总量与最终计数、错误/重启次数；缺校验量注明：
- selected population 与全队列：production/QA/internal/unknown、缺上下文原因和无标识数量：
- 漏斗单位/适用范围、操作失败/取消/恢复、限额/未知/无法关联：
- CRM独立UTC窗口/覆盖/null、计数单位、归因未关联、成熟留存分母：
- 注册快照总量/各独立维度、窗口内当前保留账号新增、与联系请求和浏览器保存的来源差异：
- 私有完整证据位置、可分享脱敏聚合包位置/哈希、保留/删除安排：

## F. 可提交需求卡与复查

| 字段 | 填写内容 |
| --- | --- |
| 事实 | 范围/样本/分母/具体证据，不写推断为事实 |
| 问题与优先级 | 阻断、数据失真、隐私或业务影响及理由 |
| 原因假设/反证/未知 | 没证据不直接归因用户意图 |
| 建议改动 | 明确UI/文案/交互/结构范围，是否获批准 |
| 验收 | 复现步骤、成功/异常/回归/隐私场景 |
| 指标 | 主指标、防误判指标、样本门、未知/失败分母 |
| 基线与发布 | 前后窗口、口径/版本、需求链接、负责人 |
| 复查 | 完整7/14/28天匹配窗口或有理由的替代；发布日为部分日时从次日起算，记录窗口边界与实际读取日期 |
| 结果 | 功能修复与业务变化分开；不足以判断也可交付 |

交接只保留最早未满足门、所需用户操作、下一安全命令/读取方法、不可重复的外部动作。若未建自动化，复查日期只是手动计划。
